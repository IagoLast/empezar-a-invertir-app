# Web

Static site for the book and investment education articles. The site is intentionally dependency free: serve `apps/web` from any static host, preserving the `/articles/` and `/img/` paths.

The visual system follows the iOS app: `#F6F9FF` canvas, navy surfaces, blue primary actions, rounded cards, and Geist typography. Spanish copy is user facing; filenames and developer documentation remain in English.

SEO assets include canonical URLs, Open Graph metadata, Book and Article JSON-LD, `sitemap.xml`, and `robots.txt`.
